Where prices come from

All prices come from Cardmarket and are in euros. The app uses two sources so you’re never left without coverage.

Condition adjustment: Cardmarket publishes one general reference price. These multipliers estimate what your copy is worth given its condition. Change them as you like.

API key (optional)

Only affects the fallback source. TCGdex needs no key at all. If you already had a pokemontcg.io key, paste it here for a higher request allowance while that source is still alive; if you don’t have one, you don’t need it (new accounts can no longer be created).

Install the app

You can install it on your phone or computer to open it with its own icon, full screen and even offline (searching and updating prices do need the internet).
Chrome, Edge or Android: press 📲 Install in the header when it appears. It shares its collection with the website.
iPhone or iPad: open the site in Safari, tap Share and then Add to Home Screen. There the installed app keeps its own collection, separate from Safari’s: move it over with Export and Import.

Danger zone
